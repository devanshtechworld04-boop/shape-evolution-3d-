# Shape Evolution 3D

A zero-backend, offline-capable 3D HTML5 WebGL browser game built with Three.js featuring **500 progressive levels**.

## Gameplay & Features
- **7 Evolution Stages:** Cube → Sphere → Pyramid → Diamond → Hexagon → Crystal → Ultimate Energy Shape.
- **4 Game Modes:** Classic (500 Levels across 10 Neon Worlds), Endless Mode, Time Challenge Mode, and Evolution Challenge Mode.
- **6 Dynamic 3D Obstacles:** Moving blocks, rotating laser gates, spinning geometric blades, falling platforms, energy barriers, and moving walls.
- **Zero-Server Persistence:** Progress, high scores, and daily rewards are stored locally via `localStorage`.
- **Portal Ready:** Includes pre-configured SDK slots in `index.html` and `PortalBridge` hooks in `game.js` for CrazyGames, GameDistribution, and GameMonetize.
