# Shape Evolution 3D

A zero-backend, offline-capable 3D HTML5 WebGL browser game built with Three.js.

## Gameplay & Features
- **7 Evolution Stages:** Cube → Sphere → Pyramid → Diamond → Hexagon → Crystal → Ultimate Energy Shape.
- **4 Game Modes:** Classic (50 Levels), Endless Mode, Time Challenge Mode, and Evolution Challenge Mode.
- **6 Dynamic 3D Obstacles:** Moving blocks, rotating laser gates, spinning geometric blades, falling platforms, energy barriers, and moving walls.
- **Zero-Server Persistence:** Progress, high scores, and daily rewards are stored locally via `localStorage`.
- **Portal Ready:** Includes `PortalBridge` hooks for CrazyGames, GameDistribution, and GameMonetize SDKs without blocking standalone offline play.

## Controls
- **Mobile:** Touch and drag left/right to steer; tap or swipe up to jump.
- **Desktop:** `A`/`D` or `Left`/`Right` arrows to steer; `W`, `Up` arrow, or `Space` to jump.
